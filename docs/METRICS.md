# 쌤씀 메모 지표 설계

서비스 목적: 선생님이 오늘 본 장면을 **짧게 남겨** 다음에 다시 보게 하는 것.  
핵심 질문은 “들어와서, 실제로 메모를 남기는가?”입니다.

## 핵심 지표

| 지표 | 정의 | 계산 | 왜 보는가 |
| --- | --- | --- | --- |
| 방문자 수 | 서비스를 연 사람 | `page_viewed` 세션 수 | 유입이 있는지 |
| 작성 시작률 | 목록에서 새 메모로 들어간 비율 | `cta_new_memo_clicked` / 방문 | CTA가 쓰이는지 |
| 메모 등록 전환율 | 작성 화면에서 저장까지 간 비율 | `memo_created` / `memo_create_started` | MVP 가치가 검증되는지 |

심화: 방문 → 새 메모 → 등록 성공 퍼널. 이탈이 목록인지 작성 화면인지를 나눕니다.

## 퍼널

1. 방문 (`page_viewed`, path `/`)
2. 새 메모 클릭 (`cta_new_memo_clicked`)
3. 작성 화면 (`memo_create_started`)
4. 등록 성공 (`memo_created`)

부가 퍼널: 상세 보기 → 수정 / 삭제. 한 번 남긴 기록이 다시 쓰이는지 봅니다.
